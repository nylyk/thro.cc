throcc GitHub

Voice chat and screen sharing for you and your friends.

One of you runs the server and the rest join with its address and an invite code.

Get the client Run a server

Voice

Calls hold up to 30 people. Voice is encoded with Opus, so everyone sounds clear and natural.

Screen share

Screens go out at up to 1440p and 60 fps, with system audio. Five people can share at once, and you pick which ones to watch.

Encryption

Voice and screen shares are end-to-end encrypted. The server forwards them without the keys to decrypt them. Compare safety numbers with someone to check it's really them.

Hosting

The server is a single binary that keeps all its data in one directory. Start it with Docker Compose and open UDP port 8476.

Learn how to host a server 
services:
  throcc:
    image: ghcr.io/nylyk/throcc:latest
    container_name: throcc
    restart: unless-stopped
    ports:
      - 8476:8476/udp
    volumes:
      - throcc-data:/data
