throcc GitHub

Voice and screen share,
on your own server.

Self-hosted and end-to-end encrypted. One binary, one data directory. Written in Rust.

Get the client Run a server

Low-latency voice

Rooms of up to 30 people. Push-to-talk or voice activation, echo cancellation and noise suppression.

Screen share up to 1440p60

With system audio, five at a time. Hardware encoded as AV1, HEVC or H.264.

End-to-end encrypted

The server relays all media but holds no key.

Simple to host

One server binary and one data directory. Joining takes an address and an invite code.
