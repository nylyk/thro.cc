throcc GitHub

Voice chat and screen sharing for you and your friends.

Self-hosted, end-to-end encrypted and written in Rust. One of you runs the server and the rest join with an invite code.

Get the client Run a server

Voice

Rooms with up to 30 people. Audio is encoded with high-quality Opus, so everyone sounds clear and natural.

Screen share

Share your screen at up to 1440p and 60 fps, with system audio. You pick which shares to watch.

Encryption

Voice and screen shares are end-to-end encrypted. The server forwards them but can't listen in. Compare safety numbers with someone to check it's really them.

Hosting

Start the server with Docker Compose and open UDP port 8476.

Learn how to host a server 
services:
  throcc:
    image: ghcr.io/nylyk/throcc:latest
    container_name: throcc
    restart: unless-stopped
    ports:
      - 8476:8476/udp
    volumes:
      - throcc-data:/data
